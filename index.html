04 FAQ

Who is Cris Nahine?
Cris Nahine is an AI engineer and senior Ruby on Rails developer who builds tools for AI coding agents. Cris created rails-ai-context, a Rails MCP server, and anatomiya and chameleon, two plugins that teach coding agents a repository's own conventions.
What is rails-ai-context?
rails-ai-context is an open-source Ruby gem and MCP server for Rails apps. It gives AI coding agents (Claude Code, Cursor, GitHub Copilot, OpenCode, Codex CLI) 35 read-only tools to look up the app's real schema, models, routes, controllers and views. It is listed in the MCP Registry.
What is an MCP server, and why does a Rails app need one?
MCP (Model Context Protocol) is the open standard AI agents use to call outside tools. Without one, an agent guesses column names, routes and associations from file names. A Rails MCP server lets it ask the app instead, so the code it writes matches the app that exists.
What is anatomiya?
anatomiya is a Claude Code plugin that learns a repository's house rules from its code and git history, in nine languages, and checks a branch before review. In 560 measured sessions, agents with it reused the existing helper 542 times; without it, 291 times.
What does Cris Nahine work on?
AI developer tooling (MCP servers, agent plugins, code search and code intelligence) and production Ruby on Rails: payment platforms, PropTech and SaaS, on PostgreSQL, Redis and AWS.
